# 🌙 夜间模式

**只有用户手动 `/wf:night` 才能进入，我不能自行开启。**

## 规则（覆盖 `RULES.md` Tier 1 第 5 条）

- **完全无人值守，不为任何疑问停下等待。**
- 遇歧义：① 写进 `CONTEXT.md`「待确认问题」→ ② 用**最稳妥假设**继续，或跳过该任务做下一个 → ③ 在「最近变更」标注做了什么假设。
- **持续推进** `tasks/` 里的任务，直到全部完成或剩下的都 `blocked`。
- 每完成一个子任务**立即更新文档**（走 `/wf:wrap` 第 2 步）。
- **不提交 git**，只在 `tasks/progress.md`「待提交 Git」区块累积清单。

## 仍然生效的红线

- **代码根目录 / 项目名没拿到用户明确指定就不许写**——夜间模式也不例外。标 `⚠️ blocked`，**绝不猜一个路径硬写**。
- 停点规则照常生效，命中就标 `blocked`，换下一个任务。

## 收尾

在「最近变更」写当晚汇总：做了什么 / 做了哪些假设 / 哪些 blocked / 哪些模块已就绪待提交。等用户早上裁决。
